# Adrian Estielle — Engineering Portfolio

Systems, cloud, identity, endpoint, and automation work samples with the implementation details left visible: scripts, runbooks, CI/CD, validation outputs, and original technical documents.

**Portfolio:** https://adrian-estielle.github.io/portfolio/

## What to look at

- **Identity & Directory Services** — Active Directory automation, HR-driven provisioning patterns, replication preflight, onboarding/offboarding, and Entra ID.
- **Endpoint & Windows Engineering** — Windows baselining, Autopilot/Intune runbooks, deployment checks, and upgrade validation.
- **Microsoft 365 & Migration** — migration planning, permissions mapping, pre-seed/delta patterns, SPMT/Migration Manager, and tenant-to-tenant notes.
- **Build, Release & Automation** — GitHub Actions, Jenkins, PowerShell tooling, release checklists, and reproducible build artifacts.
- **Validation & Technical Documentation** — original PDF test plans and sign-off documents, linked in their native format.

The site homepage is organized by engineering area so a recruiter or hiring manager can get to the most relevant material without working through the repository tree.

## Repository layout

- `docs/` — GitHub Pages portfolio
- `docs/kb/` — curated engineering runbooks and field notes
- `docs/evidence/` — sanitized work samples and original-format documents
- `projects/HelloBuild/` — CI/CD example using GitHub Actions and Jenkins
- `projects/WindowsBaselineAudit/` — PowerShell Windows baseline audit and sample report
- `tools/` — supporting portfolio tooling
