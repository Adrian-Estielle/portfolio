HOW I WORK

Infrastructure ownership, not isolated administration.

My background spans frontline troubleshooting through systems administration, cloud and endpoint engineering, enterprise migrations, and engineering automation. I approach infrastructure changes from both directions: how the architecture should work and what actually happens when the change reaches a server, endpoint, administrator, or user.

Identity & Windows

Active Directory, Group Policy, DNS/DHCP, Windows Server, Entra ID, authentication/access troubleshooting, identity lifecycle, and hybrid identity.

Cloud & Microsoft 365

Azure infrastructure and migrations, Exchange Online, Teams, SharePoint, OneDrive, backup/DR, monitoring, and collaboration platform operations.

Endpoint Engineering

Intune, Autopilot, Jamf, BitLocker, configuration and compliance policy, application deployment, remediation, and large-scale Windows deployment.

Automation & Validation
