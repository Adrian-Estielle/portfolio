# Portfolio site

This directory contains the GitHub Pages site for Adrian Charbonneau's systems and infrastructure engineering portfolio.

## Public navigation

- `index.html` — recruiter / hiring-manager landing page
- `case-studies.html` — concise infrastructure case studies
- `notes.html` — technical runbooks and field notes
- `evidence.html` — curated sanitized evidence hub
- `evidence/documentation.html` — document index with original-format PDFs as the primary links

## Publishing approach

The public site is intentionally layered:

1. **Landing page:** role positioning and high-level technical areas.
2. **Case studies:** problem, design decisions, execution, validation, and operational result.
3. **Runbooks / KB:** implementation and troubleshooting detail.
4. **Evidence:** sanitized scripts, validation documents, checklists, and reproducible project artifacts.

Public artifacts should not contain credentials, tenant identifiers, internal hostnames, private URLs, customer data, proprietary screenshots, or other confidential implementation details.
